# Feature Traceability Matrix (FTM) — Phase 01 to Phase 11
**Project**: TampilKit Studio — AC Service Booking System  
**Edition**: Basic Field Service (CoolCare AC Service)  
**Date**: 2026-10-28  
**Release Target**: Basic Field Service v1.0.0  

---

## 1. Status Legend
- **PASS**: Fitur diimplementasikan, diverifikasi dengan kode sumber aktual, model database, dan pengujian otomatis (Unit/E2E) lulus tanpa kegagalan.
- **PARTIAL**: Sebagian fitur berjalan, namun terdapat batasan atau bagian tertentu yang memerlukan penyempurnaan.
- **BLOCKED**: Verifikasi terhalang ketergantungan eksternal (misal: kredensial langsung pihak ketiga dari user belum tersedia).
- **FAIL**: Implementasi gagal memenuhi kriteria penerimaan.
- **NOT_IMPLEMENTED**: Fitur tidak ditemukan pada basis kode.
- **NOT_TESTED**: Fitur terimplementasi namun belum memiliki pengujian otomatis khusus.
